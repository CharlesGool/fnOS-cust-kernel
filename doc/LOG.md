## 缺陷

- [ ] 缺少 `houmo-drv-xh2`(`xh2a_drv.ko`): 飞牛包里有, 没有源码.
- [ ] `rtl8733bu` 用的是 5.15.12-123 的近似版本, 飞牛用的 -264 找不到源码.
- [ ] `r8169` 厂商驱动是 6.022.00 占位版本.
- [ ] NVIDIA 开源模块不含飞牛对 CMP 40HX 的改动.
- [ ] i915, xe 中 4 组疑似私有改动未还原(不影响存储和权限).
- [ ] md 还原完成度较低: `md_do_sync` 少 18 条指令, `mddev_create_serial_pool` 少一处判断, raid10 大函数未逐段比对.
- [ ] 外置模块只测了加载和卸载, 没有在对应硬件上测试.

## 限制

- 网卡, bonding, 无线和 NVIDIA 的实际功能在 KVM 测试机上无法测试, 需要真机.
- RAID5, 在线转 llbitmap, btrfs 快照和 qgroup, ZFS 镜像只在命令行测过, 未经飞牛网页创建和管理.

## 决策

| 日期 | 决策 | 状态 | 原因 |
| --- | --- | --- | --- |
| 2026-11-24 | 停留在 fnOS 1.2.1000, 内核自己维护, 移植到 6.18 LTS | 接受 | 飞牛不公开内核源码, 原装内核无法获得上游修复. |
| 2026-11-24 | 不跟进飞牛官方的新版本 | 接受 | 新版本同样不提供源码, 无法审查和修补. |
| 2026-11-26 | 只维护一个内核, 6.18.18 还原树只作比对参照 | 接受 | 两套并行会使安全修复和测试工作加倍. |
| 2026-11-26 | 项目特例: 豁免 all-in-one Skill 发布流程 `版本标识` 规则 2(正式版本只用 `vMAJOR.MINOR.PATCH`). 范围: 本项目的标签和 Release. 限制: 标签必须是 `v<上游版本>-<修订号>`, 与包版本一致 | 接受 | 包版本由上游内核版本和修订号组成, 已嵌入 deb 并被使用. |
| 2026-11-26 | 仓库按 GPL-2.0-only 授权 | 接受 | 内核补丁是 Linux 的衍生作品. |
| 2026-11-26 | Release 同时提供 deb 和完整源码(上游源码包, 外置模块源码包) | 接受 | 分发二进制需满足 GPL 的源码提供义务. |
| 2026-11-26 | 反推阶段的工具, 比对记录和飞牛二进制不公开 | 接受 | 构建不需要它们, 且含飞牛二进制和反汇编. |
| 2026-11-26 | NVIDIA 闭源驱动的源码不再由本项目分发, 使用者按需用 `ck.sh fetch-nvidia` 从 NVIDIA 下载 | 接受 | NVIDIA 许可协议对再分发有条件限制, 由使用者自行接受更清楚. |
| 2026-11-26 | 构建需要的全部下载由 `ck.sh container`, `ck.sh fetch` 完成并校验, README 事先列出 | 接受 | 其他人只靠本仓库和公开下载就能完整编译. |
